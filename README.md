## Selected projects

### Slotafy · Full-stack SaaS product

An independent multi-tenant restaurant platform that I designed, built, deploy, and operate. It covers public ordering, diner sessions, table management, real-time kitchen workflows, staff administration, billing, and payments.

- **Architecture:** .NET 10 backend with domain, application, infrastructure, and database initialization layers
- **Frontend platform:** Angular 21 and Nx monorepo with dedicated public, diner, admin, kitchen display, and back-office applications
- **Real-time and data:** SignalR, PostgreSQL, Redis, and MinIO
- **Delivery:** Docker, Kubernetes/k3s, Helm, Argo CD, GitHub Actions, and Cloudflare
- **What it demonstrates:** SaaS multi-tenancy, domain modeling, real-time workflows, modular frontend architecture, Stripe payments, GitOps, and end-to-end product ownership

<sub>The product repository is private.</sub>

### [Spur](https://github.com/AdelSS04/Spur) · .NET error-handling toolkit

An open-source, HTTP-first `Result<T>` ecosystem for explicit and type-safe error handling in modern .NET applications.

- Fluent sync/async pipelines with validation, mapping, recovery, and pattern matching
- ASP.NET Core Problem Details integration plus EF Core, FluentValidation, and MediatR packages
- Roslyn analyzers, source generators, Native AOT support, testing helpers, and benchmarks
- Demonstrates API design, performance awareness, package architecture, developer experience, and compile-time safety

### [Cosmigrator](https://github.com/AdelSS04/Cosmigrator) · Azure Cosmos DB migrations

An open-source .NET framework for version-controlled and reversible Cosmos DB document migrations.

- Forward and rollback migrations with history tracking and automatic discovery
- Bulk document operations, retry handling, CLI commands, and practical migration samples
- Designed for CI/CD pipelines, Docker workflows, and Kubernetes init containers
- Demonstrates distributed data migration, operational safety, Azure SDK design, and reusable tooling

### SnB · Geo-proximity marketplace backend

A freelance backend project for a location-aware marketplace with **100K+ downloads** and **50K+ monthly transactions**.

- Location-based discovery, Google Maps integration, push notifications, and Redis caching
- Containerized deployment and production-focused backend services
- Demonstrates scalable API design, geospatial workflows, caching, integrations, and real-world product delivery
