## Featured work

### [Cosmigrator](https://github.com/AdelSS04/Cosmigrator)

A .NET migration framework for Azure Cosmos DB that brings version-controlled, reversible document schema changes to NoSQL workloads. It supports forward and rollback migrations, bulk operations, CLI workflows, CI/CD, and Kubernetes init-container scenarios.

### [Angular Reactive Forms Showcase](https://github.com/AdelSS04/angular-reactive-forms-showcase)

A practical reference for strongly typed Angular reactive forms, reusable validators, custom controls, nested forms, error handling, route protection, and maintainable form architecture.

### [NLog Showcase](https://github.com/AdelSS04/NlogConsoleLog)

An interactive .NET project demonstrating structured logging, correlation, exception handling, performance monitoring, environment-specific configuration, and cross-platform CI/CD.
